# Yousef AI Studio Free

Isolated, manual GitHub Actions pilot for OpenMontage public zero-key demo videos. It does not interact with DigitalOcean, Supabase, OpenClaw or Layan.

Open Actions > OpenMontage Free Demo Render > Run workflow. Select a sample, then download the MP4 artifact from the finished run.

Keep this public repository free of customer data, private media, secrets, and hotel files.

The renderer is pinned to OpenMontage commit `08e2151fa02de28a5d6a312b3d575692bf147ad7`.
